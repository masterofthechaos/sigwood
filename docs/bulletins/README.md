# Bulletins

Dated watch-notices for defects/gotchas/decisions. `active/` = live; `closed/` = resolved (moved, not
deleted). Naming: `YYYY-MM-DD-<slug>.md`. Each carries `Status: Active|Closed` and, where relevant,
`file:line` evidence and resolution criteria. **Lifecycle rule:** move to `closed/` the moment it's
resolved — a resolved bulletin stranded in `active/` is the classic drift trap.
